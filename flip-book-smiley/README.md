# Flip Book Smiley

A simple flip book animation of a smiley face that cycles through Neutral, Happy, and Sad expressions.

## Structure

- `index.html`: The main animation page.
- `pages/`: Individual pages for each expression.
- `images/`: SVG images for the expressions.
- `style.css`: Styling for the flip book.
- `script.js`: Logic for cycling the images.

## Usage

Open `index.html` in your web browser to view the animation.
