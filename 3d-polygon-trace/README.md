# Infinite 3D Polygon Trace Drawer

A simple WebGL animation of a rotating 3D polygon wireframe.

## Structure

- `index.html`: The main page.
- `style.css`: Styling for the canvas.
- `script.js`: WebGL logic for rendering the polygon.

## Usage

Open `index.html` in your web browser. Note that this requires internet access to load the `gl-matrix` library from a CDN.
